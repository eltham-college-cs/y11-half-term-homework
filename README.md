# eltham-college-cs.github.io

Computer Science homework site for Eltham College, served by GitHub Pages.

- `index.html` – landing page
- `year11-csharp/` – Year 11 C# homework (OCR J277 2.1.2, 2.2.1–2.2.3)
  - `homework.html?hw=03` – a homework page
  - `verify.html` – teachers paste a report's verification code here
  - `assets/` – engine, styles, jsPDF, and the homework list (`homeworks.js`)
  - `content/` – encoded homework files, generated by the build script in the separate source folder

The question sources (with answers) are kept **outside** this repo so students can't read them.
